## Phase 01 · 权威 16s 整数时钟与三态容器对齐

### 1.1 修改文件
- `crates/gentactix-core/src/state/mod.rs`
- `crates/gentactix-core/src/sim_loop.rs`

### 1.2 具体施工步骤
1. **无损整数时钟替换浮点累加**：
   - 在 `SimWorld` 中新增 `pub epoch_seconds: u64`（默认 `23400` 即 `06:30:00`）与 `pub clock_seconds: u64`；
   - 每次 16s 步长推进（`step_subtick_5m` / `step_subtick_16s`）：
     ```rust
     self.subtick += 1;
     self.clock_seconds = self.epoch_seconds + ((self.subtick as u64) << 4);
     self.clock_hours = (self.clock_seconds as f64 / 3600.0) as f32;
     ```
   - 新增 `pub fn clock_hms_string(&self) -> String`，格式化 `"HH:MM:SS"`。
2. **三态容器完善**：
   - 在 `DerivedState` 中补齐四类修改缓存槽与虚拟实例预览缓存；
   - 在 `TickScratch` 中补齐 $8\text{m}$ 网格杀伤寄存槽，确保 `reset_scratch()` 在每步结束时 `.clear()` 零分配复用。

### 1.3 验收命令
```powershell
cargo test --manifest-path "D:\tools\gentactix\Cargo.toml" -p gentactix-core
```

## Phase 02 · $2^3 = 8\text{m}$ 网格杀伤寄存与场结算实装 (P2G $\rightarrow$ Field $\rightarrow$ G2P)

### 2.1 修改文件
- `crates/gentactix-core/src/combat_logistics.rs`
- `crates/gentactix-core/src/world_grid.rs`

### 2.2 具体施工步骤
1. **铲除直接遍历单位扣血的旧逻辑**：
   - 在 `resolve_cell_strike_ex` 中，先将 `ShotPacket` 通过 `grid.inject_shot_packet(packet)` 注入目标 $8\text{m}$ 网格的 `pixel_containers`；
   - 由网格容器展开破片/射弹强度并累加该 $8\text{m}$ 格的 `suppression_density` 与 `FireFields` 威胁值；
   - 从受击 $8\text{m}$ 网格中提取驻留单位，结合地形掩体、入射角 $\cos(\theta_i)$ 与步坦协同遮蔽结算伤亡与组织度损失，结算后消费清空该格已处理的 `incoming_packets`。

### 3.1 修改文件
- `crates/gentactix-server/src/main.rs`

### 3.2 具体施工步骤
1. 在 `serialize_state` 返回 JSON 中输出 `"tick": w.subtick`、`"clock_seconds": w.clock_seconds`、`"clock_str": w.clock_hms_string()`、`"step_seconds": 16`，并为每个单位标注其与当前指挥官的编制关系（`"is_direct_subordinate": bool`）及信息场感知置信度（`"info_confidence": f32`）；

## Phase 04 · 前端全屏图台布局重构、删减与多开拖拽卡片 (`UI-01~03`, `UI-08~09`)

### 4.1 修改文件
- `web/index.html`

### 4.2 具体施工步骤（严格遵循 SD2/CMO 印刷美术风格与红字 `data-ui-id`）
1. **`UI-01` 与 `UI-02` 直接变窄**：
   - `.app` 设为 `grid-template-rows: 36px 26px minmax(0, 1fr)`；调整内边距与字号使其紧凑精悍。
2. **彻底物理删除 `UI-06`、`UI-12`、`UI-13`**：
   - 从 HTML DOM 中完全删除 `.map-tools` (`UI-06`)、`.map-stamp` (`UI-12`)、`.map-notice` (`UI-13`)。
3. **取消固定左侧栏，`UI-03` 改造为多开自由拖拽实例卡片**：
   - `.workspace` 设为单列全屏 `grid-template-columns: minmax(0, 1fr)`，`main.map-area` (`#viewport`) 100% 铺满下方屏幕；
   - 建立浮动卡片层 `#cardsContainer`；左键点击地图实例兵牌时，弹出或激活该实例的浮动卡片 `.unit-card.inspector`（挂 `data-ui-id="UI-03"`，子块 `UI-03A` 头部带拖拽与 `×` 关闭、`UI-03B` 作战实力、`UI-03C` 位置、`UI-03D` 当前意图）；
   - 支持同时点开多个实例的卡片，按住 `UI-03A` 头部可自由拖拽到屏幕任意位置；点击卡片将其设为当前手动选中态（`.active-card`）；
   - 卡片内容根据【编制关系 + 信息场 $I$】裁剪：直属己方显示全量精确数据；非直属友军仅显示番号与通报状态；敌方接触点按信息场置信度隐藏组织度与弹药（显示“未知”）。
4. **`UI-09` 改造为右上角参谋地图工具包（内含 `UI-05` 图层项）**：
   - 位于地图右上角（挂 `data-ui-id="UI-09"`），顶部包含指北针（点击复位视图）；
   - 内含草稿工具条（挂 `data-ui-id="UI-09A"`）：`[ 测距 ]`、`[ 画笔 ]`、`[ 橡皮擦 ]`，支持在地图 SVG 草稿层 `#draftLayer` 上拉线测距、手绘战术草稿与擦除；
   - 内嵌图层开关区（挂 `data-ui-id="UI-05"`，展开钮 `UI-05A`）：控制地形、地名、接触线、命令路线、火控图层显隐。
5. **`UI-08` 改造为左下角日志窗口占位**：
   - 位于地图左下角（挂 `data-ui-id="UI-08"`），深色铬合金紧凑窗口外观，显示 `作战日志 / COMMAND LOG (暂未开放)`。

## Phase 05 · `Shift+A` / 右键呼出 `UI-03M`、`UI-03M1` 四行任务矩阵与虚拟实例 (`@#1`)

### 5.1 修改文件
- `web/index.html`

### 5.2 具体施工步骤
1. **`UI-03M` 集成指令选项框（双入口触发）**：
   - 当手动选中某张 `UI-03` 卡片（或地图实例）并按下键盘 **`Shift + A`**，或在地图上**右键点击实例兵牌**时，在该实例/卡片旁弹出 `#integratedCommandMenu`（挂 `data-ui-id="UI-03M"`）；
   - 内部提供 **`[ 任务 ]`**、**`[ 事件 ]`**、**`[ 指挥 ]`**、**`[ 整编 ]`** 选项及当前已排任务队列列表（如 `#1 移动`, `#2 射击`）。
2. **`UI-03M1` 任务队列四行级联配置窗口（点击 `UI-03M` 的“任务”弹出，挂 `data-ui-id="UI-03M1"`）**：
   - **铁律：必须先选好前三行选项，才允许在地图上画点追加任务！**
   - **第一行（4 选 1）**：`[ 移动 ]` | `[ 射击 ]` | `[ 停止 ]` | `[ 撤退 ]`
   - **当第一行选 `[ 移动 ]`**：
     - 第二行：`[ 快速 ]` | `[ 正常 ]` | `[ 隐蔽 ]`
     - 第三行：场强约束路径乘数滑块（`input[type="range"]`，最大值端显示 `不受约束 · 尽可能走直线`）
     - 第四行：显示 `速度 | 预估时间 (ETA) | 体能/组织度消耗`
   - **当第一行选 `[ 射击 ]`**：
     - 第二行：`[ 快速 ]` | `[ 正常 ]` | `[ 精准 ]`
     - 第三行：射击轮数滑块（`input[type="range"]`，最大值端显示 `持续压制 · 直到弹药打光`）
     - 第四行：显示 `预估每轮射击时间 & 总射击时间 | 预估弹药消耗`
   - **当第一行选 `[ 停止 ]`**：
     - 第二行：`[ 趴下 ]` | `[ 掩体 ]` | `[ 原地不动 ]`
     - 第三行：停止时间滑块（以 16s 为步进单位）
     - 第四行：显示 `掩体减伤率 | 隐蔽加成 | 预估组织度恢复`
   - **当第一行选 `[ 撤退 ]`**：
     - 第二行：`[ 有序撤退 ]` | `[ 直接跑路 ]`
     - 第三行：选 `有序撤退` 时显示 `抛弃物资选择（不抛弃 / 抛弃重武器 / 抛弃补给）`；**选 `直接跑路` 时必须隐藏第三行（`display: none`），单位收到任务时直接启动 $I/G$ 场自治逃逸，无需也不可在地图指定方向**！
     - 第四行：显示撤退速度预估与控制权状态说明。
3. **`UI-03M2` 事件队列占位窗口（点击 `UI-03M` 的“事件”弹出，挂 `data-ui-id="UI-03M2"`）**：
   - 保持深色铬合金印刷风格统一，列出布雷、挖坑、建造、爆破、拆除、无线电、测距基础事件项。
4. **预测流线与链式虚拟实例（Ghost Instance `@#1`）**：
   - 当为某单位排入 `#1 移动` 并在地图点选终点 $P_1$ 后：
     - 根据第三行场强约束滑块乘数绘制从起点到 $P_1$ 的预测路径流线（滑块最大时为直线，较小时受场弯曲）；
     - 在终点 $P_1$ 处渲染一个带虚线框、半透明的同兵种虚拟实例 SVG 节点（`.ghost-unit`，标注 `@#1`）；
   - 当继续排入 `#2 射击`（或 `#2 移动`）时：**`#2` 的起点坐标、射程圈圆心与火控视线（`#fireLive` / `#fireBlocked`）必须从 `#1 移动` 终点的 `@#1 虚拟实例` 位置 $P_1$ 出发绘制！**

## Phase 06 · 16s 双频计时器 + $2^n$ 倍速闭环与 E2E 自动化验收

### 6.1 修改文件
- `web/index.html`
- `tests/e2e/verify_production_ui.mjs`

### 6.2 具体施工步骤
1. **16s 计时器与 $2^n$ 倍速**：
   - 默认 `running = false`（暂停）；
   - `#speed` 点击严格按 `1× -> 2× -> 4× -> 8× -> 16× -> 1×` 切换；
   - 运行态下按倍速每秒推进 `#clock`，每满 16s 逻辑秒调用一次 `/api/commit_turn`（传 `{"subticks": 1}`）结算并刷新状态；删除旧的 2.5s 无脑轮询。
2. **更新并运行 `tests/e2e/verify_production_ui.mjs` 全面校验**：
   - 校验 `UI-01`、`UI-02` 已压窄，地图 `#viewport` 全屏铺满且直抵屏幕底边；
   - 校验 `UI-06`、`UI-12`、`UI-13` 已彻底移除（`document.querySelector('[data-ui-id="UI-06"],[data-ui-id="UI-12"],[data-ui-id="UI-13"]') === null`）；
   - 校验点击多个地图兵牌可同时弹出多张 `UI-03` 卡片，且支持拖拽位置；
   - 校验选中卡片按 `Shift + A` 或右键点击兵牌可弹出 `UI-03M` 集成指令框；
   - 校验点击“任务”弹出 `UI-03M1`，切换 `移动 / 射击 / 停止 / 撤退` 四行结构完整，且 `撤退 -> 直接跑路` 时第三行自动隐藏；
   - 校验排入 `#1 移动` + `#2 射击` 时，地图上存在 `@#1` 虚拟实例且 `#2 射击` 起点源自该虚拟实例；
   - 校验 `UI-09` 工具包（含 `UI-09A` 测距/画笔/橡皮擦与 `UI-05` 图层项）、`UI-08` 左下角日志窗口占位、`UI-07` 居中四段比例尺、以及所有可见窗口的红字 `::after` 全部合规且控制台零报错。
3. 执行验收与推送：
