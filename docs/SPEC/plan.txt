PHASE 02 · 实装外置伪装异步“时间机 (Time Machine)”与五张品类时间 LUT (/v6-phase2)
--------------------------------------------------------------------------------
目标文件：
- crates/gentactix-core/src/time_machine.rs (新建外置时间机模块，并在 lib.rs 导出)
- crates/gentactix-server/src/main.rs

核心交付清单：
1. 双哈希混淆与五张 16 槽常量时间查找表（只算时间，不改业务数值）：
   - 实现 `mix_time_unit_hash(abs_sec: u64, unit_name: &str) -> u64`（`SplitMix64(abs_sec)`
     结合编译期/常量 `FNV1a_64(unit_name)`）；
   - 实现五张独立 16 槽常量表：`LUT_BULLET`、`LUT_SHELL`、`LUT_COMMAND`、`LUT_EVENT`、
     `LUT_MOVEMENT`，产出跨回合准备偏移 `tau_phase`（`1..=16`）与唯一毫秒戳 `exact_ms`
     （`1..=16000`）。
2. 时间机对内职责（`TimeMachinePendingQueue`）：
   - 拦截 `#0` 回合（`1s..16s`）内下达的一切改状态操作（射击、移动、撤退、九大工程事件与
     起爆开关、指挥指令与 AO 写 G0、整编与调谐），赋予跨回合准备时间
     `T_prep = (16 - t_cmd) + 16 * k_turn_skip + tau_phase`，保证 `#0` 当回合零实时改数；
   - 任务无须限制为 16s 正整数倍：在每个回合交界处，时间机将落入当前 `#k` 回合 `[1s..16s]`
     窗口内的那一截有效任务数据切出来喂给 `step_subtick_16s` 结算。
3. 时间机对外职责（`TimeMachineFramePayload` & `visibility=0` 预渲染缓冲环）：
   - 在 `serialize_state` 与 `/api/commit_turn` 导出 `time_machine_frame`：
     * 包含己方粒子、可见敌军粒子（`initial_visibility: 1`）、以及处于我方 `I_intel` 可见区外围
       “16s 最大机动半径”内的 **预渲染缓冲环敌军粒子**（`is_prerender_skirt: true`,
       `initial_visibility: 0`）的分段轨迹 `particle_tracks`；
     * 将步长引擎算完的既定命中/爆炸/完工/G场生效结果原封不动封装为 `playback_events`，
       每项附带唯一 `exact_ms` 与原装 `exact_hp_loss` / `exact_supp_add`（严禁二次切分伤害）。
4. 本 Phase 专属验收命令：
   `cargo test --manifest-path "D:\tools\gentactix\Cargo.toml" --workspace`

【硬阻断 · 强制停机等待确认】：
执行完当前 PHASE 02 的代码改动与专属测试后，必须立刻停止，汇报时间机单测（含 `#0` 冻结、
原装伤害零篡改、`abs_sec + unit_name` 复盘一致、预渲染环输出）并等待大王回复“确认”或手动
