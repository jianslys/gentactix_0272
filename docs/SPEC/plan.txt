1. 完美开发原则：严禁“懒计算/连级阉割代理”。所有单元、粒子、场输运在全盘范围内
   100% 全量真实仿真，直到本地集团军级数万粒子压测通过。
2. 时空刚性基准：严格采用二进制网格 Δx = 2³ m = 8.0 m（>> 3, & 7, * 0.125）与
   步长 Δt = 2⁴ s = 16.0 s；全核零 Exp/Log 浮点敏感计算，保证跨平台逐位确定性。
3. 严禁“单元测试孤岛欺骗”：任何数学算子必须真实接入 sim_loop.rs 主闭环及
   State/DerivedState/TickScratch 架构；严禁保留假消费（_consumed_packets）或静态 SVG 假画。
4. 强制三真闭环门禁：cargo test --workspace 全绿 + 无兜底 E2E 真实地图交互位移通关
   + 视觉零红牌重叠验收。

   - 清除 lib.rs 测试中残余的 200.0 m 假网格基准，全面切换至 Δx = 8.0 m（2³ m）、
     Δt = 16.0 s（2⁴ s）；
   - 将 fields/mod.rs 内仅服务于旧单元测试的算子正式迁移并接入 sim_loop.rs，
     打通 SimWorld 与 state::WorldState / DerivedState / TickScratch 的双缓冲读/写。
2. G 场核销双层解耦与离散 Auction 分流（严禁 Sinkhorn exp/log）：
   - 实现 Cut-cell Radon 几何投影与 9 点各向同性高斯核 K_iso；
   - 严格区分 β_mode = 0（守备/占坑状态约束，人走账回）与 β_mode = 1（排雷/筑城/救护
     积分做功，永久削减 WorldState 基底 G0 绝不回弹）；
   - 建立在途预扣池 R_pool 弛豫与 ΔC_hyst 迟滞门槛；
   - 采用确定性 Tier-B 多容量最小堆拍卖（Multi-Capacity Min-Heap Auction）替代
     浮点 Entropic Sinkhorn，杜绝跨平台漂移。
3. I 场正交双通道、火力压制源项坍塌与真 P2G/G2P 输运：
   - 拆分为 I = I_intel ⊕ (H_blast, I_threat)；侦察半衰期 T_1/2 = 64s（α_intel ≈ 0.8409）；
   - 引入双时间尺度动力学：瞬态爆炸危害 τ_blast = 9s，人员压制 τ_supp = 36s，
     自然涌现“炮火停歇后约 32s”的步兵突击窗口；
   - 实现 3 态施密特触发器（Active / Pinned / Prone）：重炮轰击推高目标格 H_blast，
     将敌方发射源压入 Prone 态使辐射源项 S_k 归零，从而令外围封锁威胁坍塌（彻底消除
     “炮轰哪里就往哪里冲”的悖论）；
   - 实现正交投影算子 P_perp(d) ∇G_safe + Scharr 梯度 + RK2 λ-流线渗透 +
     Wendland C2 双点测距标定核 K_reg；
   - 彻底删除 combat_logistics.rs 中 `let _consumed_packets = std::mem::take(...)`
     假消费与 `for uid in 0..units.id.len()` 全局线性扫描，落地真实 P2G 汇聚 ->
     网格散度输运 -> G2P 回采闭环。
4. 电台物理调谐与 128 字节稀疏 ZOH 迟滞滤波：
   - 无开方地形脊线遮挡比 ξ_k + 3 阶有理衍射透射率 T_diff(ν) + 向量点积心形天线方向图 +
     洛伦兹失谐因子 L(Δf)；
   - 内存零膨胀裁剪：严格采用每单位 ≤128 字节的稀疏指令权值向量 `Vec<(u32, f32, f32)>`
     执行二阶临界阻尼 Exact ZOH 滤波，绝对禁止为每个单位分配 2D 全图场数组；
   - 接入施密特迟滞死区（Θ_cancel = 3.5, Θ_commit = 1.8, N_dwell = 4）消除帕金森抽搐。

验收门槛：
