# GENTACTIX 外置伪装异步时间机规格书 (Non-Intrusive Pseudo-Async Time Machine & Pre-Render Skirt Codex)

- **文档编号**：`GTX-SPEC-PSEUDO-ASYNC-TIMEMACHINE`
- **定位说明**：本规格书为独立增量规范，待当前 V5.0 全栈闭环（[SPEC_V5_MATH_AND_FULL_CLOSURE_CODEX.md](file:///D:/tools/gentactix/docs/SPEC/SPEC_V5_MATH_AND_FULL_CLOSURE_CODEX.md)）交付并合龙后，再并入主规格与执行计划。
- **第一性原理（为什么只需要一个“时间机”，且粒子渲染绝不污染内核）**：
  1. **内核保护边界**：之所以严禁在 `#0` 回合中途实时结算命令，唯一目的是**防止底层内核中的“欧拉连续场（$G$ 场、$I$ 场网格）”与“拉格朗日粒子权威数值（权威坐标、血量、弹药、工事落盘）”在 `16s` 步长半路被篡改**，从而保证 `16s` 步长结算引擎的物理因果与确定性哈希稳如泰山。
  2. **拉格朗日粒子渲染天然零污染**：拉格朗日粒子在屏幕上的渲染（线性插值滑动、预渲染显隐切换、按毫秒时间戳爆特效与刷数字）是**纯单向只读下游**，根本不可能反向修改内核的欧拉场或粒子权威状态。
  3. **时间机一肩挑**：无需再拆分笨重的“入口壳 + 出口演出调度壳”两套衙门，全系统只设一个外置**“时间机（Time Machine）”**——对内按准备时间拦住 `#0` 命令、在回合交界按 `[1s..16s]` 窗口切段吐数据给步长结算引擎；对外带着 `1s 到 16s` 时钟和品类哈希表，直接驱动拉格朗日粒子的只读插值渲染、$I$ 场预渲染圈显隐与 `exact_ms` 毫秒放片。

## 第一章 · 时间机对内职责：当回合拦单、跨回合拖延与窗口切段喂数

### 1.1 严格 `1..=16` 回合秒刻度与窗口切段喂数原则
1. **回合秒刻度**：单一全局回合内部只定义 **`1s` 到 `16s`**（共 `16` 个整秒拍，**不存在 `0s` 刻度**）；全局回合编号记为 `#0, #1, #2, #3, ...`。
2. **无须绑定 `16s` 正整数倍（时间机到期切段吐数据给步长引擎）**：
   - 任务只需设最小下限（如 `16s`），**完全无须限制为 `16s` 的正整数倍**（总时长可以是 `16s`、`19s`、`23s` 或由距离/滑块自然决定的任意秒数）；
   - 步长结算引擎只管结算它自己的单个回合，与任务总长无关——**时间机只需在每个回合交界处，把该任务落入当前 `#k` 回合 `[1s..16s]` 窗口内的那一段有效数据（如本回合占用的秒数、本回合内触发的发射发数/作业量）切出来吐给步长结算引擎去结算即可**。

### 1.2 `#0` 当回合全类别拦单冻结（严禁半路改写欧拉场与粒子权威值）
1. 玩家在 `#0` 回合走表途中（第 $t_{\text{cmd}} \in \{1, \dots, 16\}$ 秒）下达的**任何会改写欧拉连续场或拉格朗日粒子权威状态的操作**——包括：
   - **射击 / 火力 (`UI-03M1 / M3`)**
   - **移动 / 撤退 (`UI-03M1`)**
   - **九大工程事件与爆破开关引爆 (`UI-03M2`)**
   - **指挥指令与 AO 对 $G$ 场的写入生效 (`UI-03M3`)**
   - **编制拆分合并、装备调整与电台调谐 (`UI-03M4 / UI-14B`)**
   一律由时间机直接拦截挂起，**在 `#0` 回合内绝对不送入步长内核结算、不改动任何底层数字，也绝对不在 `#0` 回合地图上垫播任何“手榴弹烟雾/假试射”演出**。
2. **用准备时间拖进 `#1 / #2 / #3` 回合实现错峰**：
   - 时间机为被拦截的命令打上跨回合准备时长：
     $$T_{\text{prep}} = (16 - t_{\text{cmd}}) + 16 \cdot k_{\text{turn\_skip}} + \tau_{\text{phase}}$$
   - 先把 `#0` 回合剩余的 $(16 - t_{\text{cmd}})$ 秒耗尽，再按武器/动作类别跨过 $k_{\text{turn\_skip}} \in \{0, 1, 2\}$ 个整回合、落入未来回合的第 $\tau_{\text{phase}} \in \{1, \dots, 16\}$ 秒（例如贴脸近战/轻武器最快在 `#0[16]` 下令、`#1[1]` 动手、`2s` 出伤，最慢在 `#0[1]` 下令、`17s` 出伤；火炮、工程与远距无线电 AO 则拖入 `#1` 腹地如第 `7s`，甚至 `#2`、`#3` 回合）；
   - 一旦时间机把任务起点错位顶进 `#1` 的第 `7s`（比如一段 `16s` 或 `21s` 的任务），时间机在 `#1` 交界时就把落在 `#1[7..16]` 这一截的 `9s` 数据吐给步长引擎结算，在 `#2` 交界时再把剩在 `#2` 里的那一截数据吐给步长引擎结算，天然横跨回合接缝。

## 第二章 · 双哈希混淆 + 分品类时间查找表 (只算时间，不碰业务数值)

时间机内部所有的时间错峰与毫秒偏移，统一由 **“游戏秒时间刻哈希 + 单位名字常量哈希 $\rightarrow$ 查分品类时间表”** 一步算出，零浮点、零 `rand()`、100% 方便战报复盘：

1. **极简双哈希混淆公式**：
   - 直接把**那一秒的全局游戏时间刻**（$t_{\text{abs}} = \text{tick} \times 16 + \tau$）的哈希，与**单位名字常量字符串**的编译期哈希套在一起，混出一个 64 位无符号整数 $M$：
     $$H_{\text{sec}} = \text{SplitMix64}(t_{\text{abs}}), \quad H_{\text{unit}} = \text{FNV1a\_64}(\text{unit\_name\_const})$$
     $$M = \text{mix64}\big(H_{\text{sec}} \oplus \text{rotl}(H_{\text{unit}}, 27)\big)$$
   - 复盘时只需知道“游戏第几秒”和“单位名字”，即可直接算出完全相同的 $M$，无需保存任何随机流水日志。

2. **五张独立品类时间哈希表（Per-Category Time LUTs）**：
   不同业务的时间节奏不同，拿到 $M$ 后按操作类型分别查各自独立的 16 槽常量时间表，直接产出该事件的**唯一毫秒时间戳与激活秒拍**（**严禁查表修改或切分核心算出的伤害、压制、进度数值**）：
   - **`LUT_BULLET`（子弹 / 轻武器时间表）**：准备延迟最短，毫秒偏移紧凑，表现密集连射；
   - **`LUT_SHELL`（炮弹 / 重武器时间表）**：准备延迟深，单发落弹间隔与毫秒偏移跨度大（如 `4s` 装填 + `2s` 飞行叠加查表偏移，可自然跨过回合线落入下一回合）；
   - **`LUT_COMMAND`（指挥指令与 AO 时间表）**：对应电文发报至 $G_0$ 生效的时间延迟桶；
   - **`LUT_EVENT`（九大工程与爆破时间表）**：对应工兵布雷/挖壕/起爆开关合闸的时间偏移桶；
   - **`LUT_MOVEMENT`（移动与撤退时间表）**：对应吹哨整队、起步切入移动轨线的时间偏移桶。

## 第三章 · 时间机对外职责：只读粒子插值、$I$ 场外围 `visibility=0` 预渲染环与 `exact_ms` 放片

由于拉格朗日粒子的渲染完全不会反写底层内核，时间机在接收 `16s` 步长结算引擎吐出的既定账单后，直接驱动前端在 `1s 到 16s`（`0ms 到 16000ms`）内完成以下三项零污染视觉表现：

### 3.1 $I$ 场可知范围外围的 `visibility=0` 预渲染缓冲环 (Pre-Render Skirt)
1. **外扩预渲染圈**：在当前我方信息场 $I_{\text{intel}}$ 可见区域外围，额外套上一圈**“单回合 16s 最大机动半径”的预渲染缓冲环**。
2. **隐身预挂载与跨界自动显隐**：
   - 凡处于该预渲染缓冲环内的敌军拉格朗日粒子，在回合交界时连同其本回合的线性轨迹节点一并预先挂载进渲染层 DOM/SVG，但初始强制设为 **`visibility = 0`（视觉完全透明且禁用鼠标悬停/点击交互）**；
   - 在 `0ms 到 16000ms` 时间机走表期间，这些隐身粒子同样顺着各自的线性插值轨迹 $\mathbf{x}(t_{\text{ms}})$ 实时滑行；
   - **一旦某颗粒子的当前插值坐标 $\mathbf{x}(t_{\text{ms}})$ 滑入我方 $I_{\text{intel}}$ 可见格，时间机/渲染层当场将其 `visibility` 从 `0` 切换为 `1`（若从可见格滑出至迷雾格，则当场从 `1` 切回 `0`）**；
   - 由此既彻底省去了后端单独计算“第几毫秒跨出树林进入视野”的麻烦，又消灭了回合中途动态新建 DOM 图标的卡顿，实现敌军探出林缘瞬间丝滑显影。

### 3.2 算演合一 `exact_ms` 定点触发（零脱靶）
1. 时间机为步长引擎算好的每一条既定事件（基于第二章双哈希 + 对应品类时间 LUT）赋予一个落在 `(0ms, 16000ms]` 内的唯一毫秒时间戳 **`exact_ms`**；
2. 当时间机时钟扫到某条命中/爆炸/完工事件的 `exact_ms` 时，直接取受击粒子在 **`exact_ms` 这一瞬间所处的线性插值坐标 $\mathbf{x}(\text{exact\_ms})$** 播放弹着爆炸特效，并在**同一毫秒**把步长引擎早已算好的真实伤害 `exact_hp_loss` / 压制 `exact_supp_add` / 工事转正状态刷到界面上；
3. 当 `16000ms` 走完，本回合全部既定事件 100% 兑现完毕，画面显示状态与底层 `AuthoritativeWorldState` 严丝合缝合拢。
