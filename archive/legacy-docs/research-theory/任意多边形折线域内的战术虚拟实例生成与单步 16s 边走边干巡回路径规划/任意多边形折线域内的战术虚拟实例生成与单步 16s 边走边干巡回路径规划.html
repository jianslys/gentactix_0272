Module 02 · 几何预处理与九大事件宏算子

确定性 O(K) 战术点集生成算子与九大事件宏定额矩阵

为消除多端架构（x86_64 与 ARM64）下的浮点尾数舍入漂移，系统将玩家绘制顶点量化至 8m / 1024 = 7.8125 mm 定点子格，强制逆时针（CCW）规范化并经 SplitMix64 生成循环移位不变主种子。随后按战术物理拓扑分支调用三大 O(K) 确定性生成算子，支撑 UI-03M2 全部九大工程事件宏。

模态 A · 面域阻绝 M1 布雷 / M6 爆破

周长补偿交错梅花桩与受限极坐标抖动

沿主威胁轴建立正六边形晶格，通过周长补偿因子（α=1.08, β=0.50）消除边界裁切损失，并利用三角不等式严格限制抖动半径：

δ_max = min(0.22a, 0.48·max(0, a - r_min))

在零事后碰撞检测下从代数上锁死抗殉爆安全间距（AT 雷 r_min=4.0m 时实测最小间距 4.590m），辅以 O(K) Bridson 泊松盘模态。

模态 B · 前沿筑城 M2 散兵坑 / M5 碉堡

主威胁法向驱动斜接限制内缩多梯队采样

筛选满足 n_out · n_threat ≥ 0.15 的迎敌前沿边链，沿内角平分线实施斜接截断内缩偏置（d₁=6m 主阵地，d₂=18m 预备梯队）：

v_i^(e) = v_i + d_e · min(2.5, m_i) · b_i

沿有效前沿弧长等距重采样，并为每个阵位赋予局部外法向与全局威胁方向加权合成的复合射界向量 d_k。

模态 C · 线性工程 M3 堑壕 / M4 铁丝网

抗纵射之字形折曲（Zigzag）横向微扰采样

遵循 FM 5-15 与 FM 5-103 生存力条令，在折线弧长等分节点上施加奇偶交替法向正交微扰（A_zig = 1.2m），防止敌机枪侧向纵射贯通：

w_k = p_base(s_k) + (-1)^(k+1) · A_zig · n_i
